# 🏠 Home_Lab

Bem-vindo ao meu projeto **Home_Lab**!

Este projeto tem como objetivo montar e manter um servidor pessoal para experimentar novas tecnologias, testar aplicações e explorar softwares que possam facilitar meu dia a dia.

O Home_Lab também funciona como um ambiente de aprendizado, permitindo conhecer melhor ferramentas de infraestrutura, automação, containers e serviços self-hosted.

## 🖥️ Hardware

| Componente | Especificação |
|---|---|
| Equipamento | Raspberry Pi 4 Model B |
| Memória RAM | 4 GB |
| Armazenamento principal | Cartão SD de 64 GB |
| Armazenamento adicional | SSD de 256 GB |

## ⚙️ Infraestrutura

- **Sistema operacional:** Ubuntu Server
- **Orquestração de containers:** K3s

## 📦 Aplicações

Aplicações instaladas ou utilizadas no Home_Lab:

- [Pi-hole](./aplicacoes/pi-hole/) — bloqueio de anúncios e gerenciamento de DNS.
- [Tailscale](./aplicacoes/tailscale/) — acesso remoto seguro à infraestrutura.
- [K3s](./infraestrutura/k3s/) — orquestração leve de containers Kubernetes.

## 🛠️ Aplicações Próprias

Espaço destinado aos projetos e aplicações desenvolvidos por mim para ampliar as funcionalidades do Home_Lab.

## 🎯 Objetivos do Projeto

- Experimentar novas aplicações e tecnologias.
- Aprender sobre infraestrutura e administração de servidores.
- Hospedar serviços pessoais.
- Automatizar tarefas do dia a dia.
- Desenvolver aplicações próprias.
- Documentar instalações, configurações e experiências.

---

Este é um projeto pessoal e experimental, em constante evolução.

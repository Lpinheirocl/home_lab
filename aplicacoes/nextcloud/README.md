# [Nextcloud](https://github.com/alexta69/metube?tab=readme-ov-file) 
Nextcloud serve para criar uma plataforma de armazenamento em nuvem, colaboração e sincronização de arquivos, oferecendo mais controle e privacidade sobre seus dados, já que pode ser hospedado em um servidor próprio.

Criar as pastas
```bash
sudo mkdir -p /mnt/ssd/nextcloud-data
sudo mkdir -p /mnt/ssd/nextcloud-db
sudo chmod 777 /mnt/ssd/nextcloud-data /mnt/ssd/nextcloud-db
```
